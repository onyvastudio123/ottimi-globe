# Ottimi x Heckmondwike - Trip Globe

Live: https://onyvastudio123.github.io/ottimi-globe/

An interactive 3D globe of the school trip programme. Click a point for the dates, the year group, what Ottimi provides, and a photo or video. Built to be embedded in a Canva presentation.

## Updating the trips

Open the live page and press E for the editor. Make the changes, press Download data.json, then replace data.json in this repository. The globe picks it up on the next load.

A Google Sheet can be connected instead, in which case the sheet becomes the source of truth and data.json is only a fallback.
